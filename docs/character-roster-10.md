# Loverman 新增男性角色设定集

## 通用美术规范

- 人物年龄均为 22～31 岁的成年男性，不使用儿童比例。
- 风格延续 Loverman 的柔和 3D、樱花之城和甜点色环境，但脸部更成熟：头身比约 5.5～6 头身，肩线更宽，五官更立体。
- 图鉴展示使用透明半身立绘，头顶到腰线，三分之二侧身或正面，视线看向玩家。
- 每名角色的主色、发型、服装轮廓和配饰必须一眼可区分。
- 不使用真实品牌、现成名人和水印。

## 1. 裴予川

- **年龄 / 身份**：27 岁，花艺策展人，经营樱花巷尽头的玻璃花房。
- **外形**：蜜茶棕侧分短发，浅绿针织开衫、白衬衫和银色叶片胸针，笑容温和，站姿放松。
- **主色**：鼠尾草绿、象牙白。
- **性格**：温柔、细心、有边界感，擅长照顾人但不替别人做决定；偶尔用花语逗人。
- **互动方式**：先观察主角的情绪，再给出含蓄回应。喜欢被直接需要。
- **图鉴定位**：温柔治愈型，但不是无原则的“中央空调”。
- **第一章钩子**：他为一位匿名客人准备花束，邀请主角从残落花瓣里推断收花人。
- **判定偏好**：洞察力、情商。

## 2. 祁观澜

- **年龄 / 身份**：29 岁，古籍修复师，兼任樱花之城档案室顾问。
- **外形**：墨黑及肩发低束，细银框眼镜，炭灰高领衬衫、米白修复手套，冷淡而整洁。
- **主色**：墨黑、冷银。
- **性格**：克制、严谨、有冷幽默；不擅长表达关心，却会默默修好主角损坏的东西。
- **互动方式**：重视承诺和证据。随意试探会被看穿，坦诚表达反而能让他放下防备。
- **图鉴定位**：禁欲系、可靠年上。
- **第一章钩子**：一册旧书被送回档案室，缺失的页码里出现了主角的名字。
- **判定偏好**：才智、洞察力。

## 3. 楚曜

- **年龄 / 身份**：25 岁，青年钢琴家，樱花音乐厅驻场演出者。
- **外形**：香槟色微卷发，单边银耳钉，象牙白礼服外套配黑色丝带，手指修长，舞台感强。
- **主色**：香槟金、象牙白。
- **性格**：礼貌、优雅、有距离感，内里叛逆且厌倦被包装成完美偶像。
- **互动方式**：对客套话没有兴趣。主角指出他的真实情绪时，他会第一次主动靠近。
- **图鉴定位**：华丽天才、舞台反差。
- **第一章钩子**：他匿名留下一段未署名钢琴曲，希望主角找到真正的作曲者。
- **判定偏好**：美貌、情商。

## 4. 霍闻舟

- **年龄 / 身份**：31 岁，城市救援队队长，负责樱花市集大型活动安全。
- **外形**：利落黑短发，眉骨有浅疤，深海军蓝机能夹克、贴身黑衫和工作手套，身形高大可靠。
- **主色**：海军蓝、安全橙。
- **性格**：成熟、果断、保护欲强，但容易把危险都留给自己；不擅长接受照顾。
- **互动方式**：行动比语言重要。主角在关键时刻做出可靠判断，会得到他的尊重。
- **图鉴定位**：成熟可靠的硬朗年上。
- **第一章钩子**：一次市集临时事故后，他请主角帮忙寻找走失的孩子，却隐瞒了自己的旧救援创伤。
- **判定偏好**：情商、洞察力。

## 5. 闻雪川

- **年龄 / 身份**：26 岁，气象摄影师，专门拍摄樱花之城的极端天气。
- **外形**：蓬松银发、冰蓝眼睛、白色摄影夹克和浅蓝围巾，相机背带挂着一枚旧镜头吊坠。
- **主色**：冰蓝、雪白。
- **性格**：外向、爱冒险、爱开玩笑，惯用镜头记录别人，却很少让别人拍自己。
- **互动方式**：喜欢即兴行动。主角愿意陪他疯一次，比说很多安慰的话更有效。
- **图鉴定位**：银发冒险系，和“冷面银发”形成反差。
- **第一章钩子**：他拍到一张照片，里面是尚未去过某个地点的主角。
- **判定偏好**：洞察力、情商。

## 6. 宋照

- **年龄 / 身份**：28 岁，剧院首席演员，正在排练一部没有结局的爱情剧。
- **外形**：红棕侧分卷发、酒红舞台外套、金色耳饰，眉眼生动，表情变化明显。
- **主色**：酒红、暖金。
- **性格**：舞台上游刃有余，舞台下认真敏感；害怕别人只爱他的表演人格。
- **互动方式**：他擅长试探和调情，但只有主角看穿台词背后的真心时，关系才会前进。
- **图鉴定位**：明艳戏剧系、会撩但缺安全感。
- **第一章钩子**：他请主角临时对戏，剧本里的台词却逐渐对应两人的真实经历。
- **判定偏好**：美貌、情商。

## 7. 程砚礼

- **年龄 / 身份**：24 岁，甜品店年轻继承人，专门复刻失传配方。
- **外形**：栗色短发、奶白衬衫配焦糖色围裙、袖子卷到小臂，鼻尖偶尔沾着面粉。
- **主色**：焦糖、奶油白。
- **性格**：认真、直球、容易害羞；谈起甜点会变得自信，谈起喜欢的人却总绕弯。
- **互动方式**：鼓励他的作品、认真品尝并给出真实反馈，比夸他本人更容易打开话题。
- **图鉴定位**：小狗系甜点师、认真直球。
- **第一章钩子**：他想复刻主角童年吃过的甜点，却不肯说明是谁告诉他的。
- **判定偏好**：情商、才智。

## 8. 谢无咎

- **年龄 / 身份**：30 岁，移动天文馆馆主，也替市集占卜节庆天气。
- **外形**：黑色长发半束、紫色眼睛，深色长外套绣有星轨，戴银色细戒指，姿态从容。
- **主色**：午夜紫、银白。
- **性格**：平静、神秘、尊重自由意志；说话像谜语，但不会操控别人做选择。
- **互动方式**：他不喜欢被要求“预言未来”。主角坚持自己决定命运时，他会露出真正的笑意。
- **图鉴定位**：神秘占星系，但不是故弄玄虚的骗子。
- **第一章钩子**：他准确说出主角今天会来，却拒绝说明接下来会发生什么。
- **判定偏好**：才智、洞察力。

## 9. 唐栖

- **年龄 / 身份**：22 岁，电竞战队队长兼赛事解说。
- **外形**：蓝黑短碎发、银色耳骨夹、青色宽松外套、黑色半指手套和头戴式耳机。
- **主色**：电光青、曜石黑。
- **性格**：话多、好胜、反应快，输了会嘴硬，真正被误解时却会独自消化。
- **互动方式**：喜欢有来有回的玩笑和公平竞争；主角不把他当小孩，他会格外认真。
- **图鉴定位**：年下电竞系、热血直球。
- **第一章钩子**：一名匿名玩家发来比赛录像，坐标指向市集废弃游戏厅。
- **判定偏好**：美貌、洞察力。

## 10. 梁星野

- **年龄 / 身份**：29 岁，独立建筑师，夜间担任天文台志愿者。
- **外形**：深棕微卷发、琥珀色眼睛，黑色高领衫和灰色长大衣，随身携带图纸筒和银色耳饰。
- **主色**：石墨灰、琥珀棕。
- **性格**：疏离、专注、有轻微完美主义，不擅长察言观色，却会记住别人随口说过的偏好。
- **互动方式**：不要催他给答案，给他时间把关心落实成具体设计，他会用作品表达感情。
- **图鉴定位**：寡言建筑师、笨拙但深情。
- **第一章钩子**：他设计了一座没有业主的观景亭，而草图与主角童年的秘密基地一模一样。
- **判定偏好**：才智、情商。

## 首轮建议优先级

优先制作以下四人，能最快补齐现有阵容的类型缺口：

1. **霍闻舟**：成熟硬朗，补足年上和救援职业。
2. **程砚礼**：甜点直球，与樱花市集的核心场景直接关联。
3. **宋照**：舞台反差，提供更强的表情和剧情表现。
4. **闻雪川**：银发冒险型，利用现有画风也能形成鲜明差异。

后续六人可按章节地图分批开放：

- 花房：裴予川
- 档案室：祁观澜
- 音乐厅：楚曜
- 剧院：宋照
- 天文馆：谢无咎
- 游戏厅与观景亭：唐栖、梁星野
